# Vitals Tracker Pro 🏋️‍♂️🍎

A high-performance fitness OS designed for athletes and gym rats to track workouts, nutrition, and health metrics in one place.

## Current Features
*   **User Authentication**: Secure sign-in/sign-up flow.
*   **Database Sync**: Real-time data storage via **Supabase**.
*   **Workout Logger**: Track sets, reps, and weights for progressive overload.
*   **Macro Tracker**: Monitor daily protein, carbs, and fats.
*   **Health Dashboard**: Visualize body weight and hydration trends.

---
Built with **React**, **Tailwind CSS**, and **Lovable**.

## 🛠️ Upcoming Features (Roadmap)
*   **PR Tracker**: A dedicated section to celebrate and track Personal Records for major lifts.
*   **Rest Timer**: Built-in stopwatch for optimized recovery between sets.
*   **Meal Presets**: Quick-add buttons for common athlete meals (e.g., Post-workout shake).
*   **Social Feed**: Future capability to share progress or follow other athletes.
